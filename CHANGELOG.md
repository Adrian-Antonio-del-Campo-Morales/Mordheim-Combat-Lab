# Changelog

## 0.9.0-beta.1

- First public beta release of the unified Mordheim Combat Lab.
- Added bilingual movement-unit display: inches in English and centimetres in Spanish.
- Audited equivalent Mordheimer and Trollheim warbands using canonical family identities.

## 0.1.0

- Created Mordheim Combat Lab as a new unified application and package.
- Materialized 49 Mordheimer and 34 Trollheim bands into one schema-versioned contract.
- Added All/Core/1A/1B/1C/Trollheim catalogue filtering and source-labelled variants.
- Added persistent language/category preferences and bilingual application navigation.
- Introduced the Combat Lab Excel marker with catalogue metadata and stable IDs.
- Renamed the Windows executable, installer, native package, and launch command.

## 1.1.0

- Redesigned the interface for a clearer, more polished visual experience.
- Improved the layout and styling of controls, panels, and results.

## 1.0.0

- First public release of Mordheim Combat Lab.
- Added an independent English Mordheim knowledge base covering 49 warbands and 318 profiles.
- Added canonical warband, warrior, weapon, armour, equipment, skill, poison, material, and preparation filtering.
- Added configurable candidates, weighted random opponents, and manually configured opponents.
- Added weapon, equipment, and multi-advance Monte Carlo comparisons with cancellable runs.
- Added optional house rules, cost-aware MOTTA ranking, and reusable Excel workbooks.
- Added concise rules-focused tooltips for every visible weapon and armour option.
- Added a compiled Cython combat kernel to the portable Windows executable.
